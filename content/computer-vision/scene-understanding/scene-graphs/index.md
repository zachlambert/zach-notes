# Image retrieval using scene graphs

{{<paper.ref label="johnson-scene-graph-image-retrieval"/>}}

Introduces the concept of scene graphs as a description of the relationship between objects in a 2D image.

Requires describing the objects in an image as well as their *attributes* and *relationships*, called **detailed semantics**.
